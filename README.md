WOLFFLIX for PS5 (homebrew)  -  version 1.00.010  -  title ID PPSA90653
=======================================================================

Watch Wolfflix on a jailbroken PS5: movies, TV shows, anime (sub or English dub), Live TV,
with Continue Watching, My List and profiles shared with the website.

WHAT YOU NEED
  - A jailbroken PS5 with a homebrew loader that installs app folders from /data/homebrew
    (for example ShadowMountPlus, or etaHEN's homebrew support).
  - An FTP server running on the PS5 (most jailbreak setups include one).
  - Tested on firmware 13.60.

INSTALL
  1. Unzip Wolfflix-PS5-PPSA90653-v1.00.010.zip. You get a folder called PPSA90653.
  2. Copy the whole PPSA90653 folder to /data/homebrew/ on the PS5 (FTP, or a USB drive
     and your file manager), so you end up with /data/homebrew/PPSA90653/eboot.bin.
  3. Let your homebrew loader register it (with ShadowMountPlus: run it / reboot), and
     Wolfflix appears on the home screen.

UPDATING
  Copy the new PPSA90653 folder over the old one. Your account and settings stay: they are
  kept in the app's own save space, not in the folder.

FIRST LAUNCH
  The app creates a Wolfflix account for your console automatically - nothing to sign up
  for. If you already have a Wolfflix website account, you can use it instead from
  Options > Account ("Already have a Wolfflix website account?").

CONTROLS
  D-pad / stick = move
  X = open / play / pause 
  O = back
  L1 / R1 = sections        
  Triangle = search             
  Options = account
  
  In the player:  
  D-pad / stick Left/Right = Skip 10 s 
  L1/R1 = Skip 1 min
  Square = server, audio and subtitles
  Triangle = stats (for nerds)
